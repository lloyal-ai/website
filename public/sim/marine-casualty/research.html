Lloyal · Live attention · Research basis

Lloyal gives application developers deterministic control over a model’s live attention state—here’s why that matters.

TL;DR / what follows
  • Calling a model endpoint again is a new draw, not continuation. Agent runs diverge early, and nominally deterministic hosted settings do not guarantee the same execution.
  • New evidence creates a control problem inside inference. Applications need to decide which live trajectories receive it, what may continue and which state can become the future—not merely append another prompt chunk.
  • Lloyal makes the instantiated trajectory application state. Application code can hold a lineage, admit evidence only where it applies, fork from that exact parent state and determine what may continue—without starting intelligence again from its transcript.

Restarting preserves a transcript. It does not preserve the execution already underway.

The literature converges on four pressures: reruns diverge early, hosted calls vary under nominally deterministic settings, corrected evidence creates a conflict problem, and replaying a transcript cannot recover the live state that produced it.

What the research establishes

Together, these findings explain why Lloyal’s control surface matters; the live simulation makes the application-level contrast visible.

01

A replacement run becomes a new trajectory.

A KTH arXiv preprint analysed 60,000 SWE-Bench agent trajectories across three models and two scaffolds. Across the analysed divergent run pairs, the first divergence occurred within the first 1% of each trajectory, and small differences cascaded into different solution strategies.

02

Temperature zero is not an endpoint guarantee.

Five hosted models were called ten times on identical tasks with temperature 0, top-p 1 and fixed seeds. The peer-reviewed study reported accuracy variation of up to 15%; models rarely produced the same raw response ten times.

03

A corrected fact is not merely another prompt chunk.

Models often recognise that evidence conflicts while struggling to pinpoint the conflicting spans and generate robust responses. Separate ICLR research found confirmation bias when supportive and contradictory evidence coexist.

04

Where evidence appears changes whether it is used.

Peer-reviewed TACL research found that changing the position of relevant information can significantly change model performance. Results were often strongest at the beginning or end of the context and degraded in the middle—even for long-context models. Rebuilding a prompt or appending a correction is not semantically neutral.

Application orchestration

LangGraph ↗ · Mastra ↗

LangGraph checkpoints graph state for resume, time travel and fault tolerance. Mastra can clone conversation threads, including their messages and application memory.

These are durable application-state abstractions, not ownership of an in-flight model trajectory. If generation is terminated, they can reconstruct the state around another call; they cannot resume the terminated inference already underway.

EuroSys 2025

Pensieve ↗

Pensieve retains processed conversation state across turns and reports 1.14–3.0× the throughput of vLLM and TensorRT-LLM in its evaluated workloads.

Pensieve retains processed state across turns of one conversation. It does not expose application-owned live branches, selective evidence admission or lineage policy.

NeurIPS 2024

SGLang ↗

RadixAttention reuses shared prefixes across structured language-model programs; the paper reports up to 6.4× higher throughput across workloads including agent control and RAG.

Server-managed prefix reuse is not application ownership of a live trajectory.

MLSys 2025

FastTree ↗

Calls tree-structured prefix sharing prevalent in modern LLM applications and reports up to 2.2× throughput over SGLang by co-optimising memory layout and attention computation.

It validates the tree as an inference structure, not institutional evidence admission or lineage policy.

Shared-prefix attention · 2024

Hydragen ↗

An exact shared-prefix attention implementation reporting large, workload-specific throughput gains and support for tree-based sharing.

Its reported gains are workload-specific; its relevance here is the established systems value of shared ancestry.

What deterministic means
Control over live state—not a promise of identical future tokens.

The application deterministically chooses which exact trajectory is held, forked, admitted, continued or pruned. Generation after that decision can remain stochastic.

The architectural shift
When the world changes during a valuable agent run, conventional applications can preserve a transcript and start another call. Lloyal makes the execution already underway an object ordinary application code can govern.

Published research establishes why that distinction compounds with task length: new runs diverge early, conflicting context is hard to reconcile, and rebuilding processed state is costly. The Lloyal-specific claim is application control over live lineage—what continues, what receives new evidence, and which state may become the future.
